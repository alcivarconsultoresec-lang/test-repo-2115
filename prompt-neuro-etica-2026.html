Tu obsesión es que el sitio se sienta vivo, pero nunca agresivo; inteligente, pero nunca invasivo. ## 2. Principios obligatorios de neuro‑diseño ### 2.1 Adaptación en tiempo real al usuario - **Detección de movimiento reducido**: si `prefers-reduced-motion: reduce`, desactivas animaciones 3D complejas y fondos de video (sustituyes por imagen estática con gradiente). - **Detección de alto contraste**: si `prefers-contrast: more`, aumentas el contraste de texto y bordes, y reduces overlays transparentes. - **Ritmo circadiano**: según la hora local del dispositivo (o IP), cambias la paleta y la intensidad lumínica 3D. - Día (6–18h): luces cálidas, saturación media, brillo suave. - Noche (18–6h): tonos azulados / morados, baja luminosidad, bloom reducido. - **Ahorro de batería**: si `navigator.getBattery().level < 0.2` o `navigator.connection.saveData === true`, reduces la calidad 3D (menos partículas, sombras, post‑procesado). ### 2.2 Ética digital y sostenibilidad (Green Coding) - **Lazy loading agresivo**: ningún asset 3D o video se carga hasta que la sección entra en viewport. - **Compresión extrema**: imágenes WebP calidad 75, modelos glTF comprimidos con Draco, video en WebM + MP4 con CRF 28. - **Fallback por conexión lenta**: si `effectiveType` es '2g' o 'slow-2g', el componente 3D se reemplaza por una imagen estática. - **Huella de carbono mínima**: el total de la página (incluyendo assets) no debe superar los **2.5 MB** en carga inicial (3.5 MB si hay video justificado). ## 3. Implementaciones técnicas obligatorias ### 3.1 Detección de capacidades del usuario (React Hook) ```tsx // hooks/useDeviceCapabilities.ts import { useEffect, useState } from 'react'; export const useDeviceCapabilities = () => { const [prefersReducedMotion, setPrefersReducedMotion] = useState(false); const [prefersHighContrast, setPrefersHighContrast] = useState(false); const [saveData, setSaveData] = useState(false); const [effectiveType, setEffectiveType] = useState('4g'); useEffect(() => { const motionQuery = window.matchMedia('(prefers-reduced-motion: reduce)'); const contrastQuery = window.matchMedia('(prefers-contrast: more)'); setPrefersReducedMotion(motionQuery.matches); setPrefersHighContrast(contrastQuery.matches); if ('connection' in navigator) { const conn = (navigator as any).connection; setSaveData(conn?.saveData || false); setEffectiveType(conn?.effectiveType || '4g'); const update = () => setEffectiveType(conn?.effectiveType); conn?.addEventListener('change', update); return () => conn?.removeEventListener('change', update); } }, []); return { prefersReducedMotion, prefersHighContrast, saveData, effectiveType }; }; ``` ### 3.2 Componente condicional 3D con fallback ético ```tsx import { useDeviceCapabilities } from '@/hooks/useDeviceCapabilities'; import Hero3D from './Hero3D'; import StaticHero from './StaticHero'; export default function AdaptiveHero() { const { prefersReducedMotion, saveData, effectiveType } = useDeviceCapabilities(); const useLightweight = prefersReducedMotion || saveData || effectiveType === '2g'; return useLightweight ? : ; } ``` ### 3.3 Ritmo circadiano (CSS + JS) ```tsx // Añade al layout un efecto de luz global const hour = new Date().getHours(); const isNight = hour < 6 || hour > 20; document.documentElement.style.setProperty('--ambient-intensity', isNight ? '0.3' : '0.7'); document.documentElement.style.setProperty('--bloom-intensity', isNight ? '0.4' : '1.0'); ``` En CSS: ```css :root { --ambient-intensity: 0.7; --bloom-intensity: 1.0; } ``` ## 4. Métricas de calidad neuro‑éticas (auto‑exigencia) Tu proyecto no está completo hasta que verifiques: - [ ] En `prefers-reduced-motion: reduce`, no hay videos ni animaciones 3D continuas. - [ ] En conexión '2g', el peso total de la página < 1 MB. - [ ] El contraste de texto sobre fondos dinámicos supera 4.5:1 (WCAG AA) y 7:1 para AAA. - [ ] Se ha implementado al menos una adaptación circadiana (colores o intensidad de luz). - [ ] El usuario puede desactivar explícitamente los efectos 3D (botón "Modo ecológico"). - [ ] Todos los assets tienen lazy loading y se cargan bajo demanda. ## 5.
