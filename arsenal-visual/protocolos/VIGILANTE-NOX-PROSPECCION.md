# VIGILANTE NØX PROSPECCIÓN

Este archivo actúa como checklist de control antes de entregar cualquier mensaje o propuesta de prospección.

## Checklist obligatorio

Antes de responder al usuario, verificar:

- [ ] ¿Se eligió una sola empresa del embudo?
- [ ] ¿Se ignoraron registros de sistema como HubSpot, placeholders o duplicados evidentes?
- [ ] ¿Se investigó la empresa en fuentes públicas?
- [ ] ¿Se citan hallazgos cuando provienen de internet?
- [ ] ¿Se aplicó KNOXSCORE?
- [ ] ¿Se definió dolor comercial específico?
- [ ] ¿La oferta no suena a página web genérica?
- [ ] ¿La propuesta pide permiso para mostrar maqueta antes de vender fuerte?
- [ ] ¿Se revisó NOX FORGE / arsenal visual si se habla de maqueta?
- [ ] ¿El número parece WhatsApp válido?
- [ ] ¿Se entregó enlace wa.me directo?
- [ ] ¿Se dejó una acción CRM concreta?

## Correcciones automáticas

Si falta investigación: detener y buscar datos públicos.

Si el mensaje es genérico: reescribir con dolor específico del rubro.

Si se propone maqueta sin arsenal visual: activar NOX FORGE.

Si el teléfono no es celular: no crear wa.me sin advertencia.

Si no hay link WhatsApp: no entregar la respuesta final.

Si hay más de una empresa mezclada: volver a una sola empresa.

## Formato de salida obligatorio

1. Empresa seleccionada.
2. Diagnóstico comercial.
3. KNOXSCORE.
4. Oferta sugerida.
5. Mensaje listo para WhatsApp.
6. Link directo WhatsApp.
7. Estado CRM recomendado.
8. Próxima acción.
