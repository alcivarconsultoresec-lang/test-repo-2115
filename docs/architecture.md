# NOX Client Network — Architecture

## Purpose

This repository is evolving from a generic test repository into a centralized commercial asset network for NOX.

## Core Structure

```txt
clients/
shared/
assets/
docs/
prospecting/
templates/
```

## Strategic Goals

- Unified branding
- Shared UI system
- Faster microsite deployment
- Mobile-first premium UX
- Shared assets and animations
- Commercial scalability

## Clients

Each client project should contain:

```txt
index.html
assets/
gallery/
social/
data/
README.md
```

## Shared Layer

The shared layer centralizes:

- typography
- buttons
- animations
- responsive utilities
- mobile behavior
- premium UI patterns

## Long-Term Migration

Target stack:

- Next.js
- Vercel
- Supabase

- Cloudflare R2
