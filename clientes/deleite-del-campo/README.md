# Deleite del Campo / Comida Casera

Carpeta independiente para la maqueta web del cliente.

## Ruta del proyecto

`/clientes/deleite-del-campo/`

## Assets del cliente

`/assets/clientes/deleite-del-campo/`

## Protocolo

- Cada cliente vive en su propia carpeta.
- No se sobrescribe el `index.html` raíz del repositorio.
- Las imágenes, videos y recursos van en la carpeta de assets del cliente.
- La entrega final será un enlace publicado, no archivos descargables.
